**NOMBRE DE LA BASE DE DATOS:** Heart Disease Risk Prediction Dataset / Conjunto de datos para la predicción del riesgo de enfermedades cardíacas



**¿QUÉ ES?:** Este es un conjunto de datos que esta hecho principalmente para predecir el riesgo de una enfermedad cardíaca basándose en los síntomas, el estilo de vida e historial médico de cada paciente, teniendo 70 000 muestras. Cada fila del conjunto de datos representa a un paciente, con indicadores binarios (Sí(1.0) / No(0.0)), junto con una etiqueta de riesgo calculada que indica si el paciente tiene un riesgo alto o bajo de desarrollar una enfermedad cardíaca. La cantidad de muestras lo hace una gran base de datos para entrenar modelos de aprendizaje automático en tareas de clasificación.
