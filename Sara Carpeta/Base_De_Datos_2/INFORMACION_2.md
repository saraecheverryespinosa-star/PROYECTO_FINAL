**NOMBRE DE LA BASE DE DATOS:** Medical Device Failure Dataset / Conjunto de datos sobre fallos en dispositivos médicos



**¿QUÉ ES?:** Este conjunto de datos se elaboró ​​a partir de patrones observados en múltiples registros anonimizados de mantenimiento de equipos hospitalarios, informes de ingeniería clínica y registros de incidentes simulados. El esquema y los atributos siguen las estructuras típicas que se observan en la investigación sobre predicción de fallos de dispositivos y en la bioinformática.
